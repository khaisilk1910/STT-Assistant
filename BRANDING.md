# STT Assistant — Brand assets / Bộ nhận diện

![STT Assistant logo](custom_components/stt_assistant/brand/logo.png)

Bộ nhận diện này dành cho **tích hợp cộng đồng STT Assistant**. Không dùng logo hoặc dấu hiệu chính thức của Home Assistant.

## Brand assets used by Home Assistant 2026.3+

Put the images **directly** in `custom_components/stt_assistant/brand/` (the repository already includes them):

| File | Size | Purpose |
| --- | --- | --- |
| `icon.png` | 256 × 256 | Default integration icon, light UI |
| `icon@2x.png` | 512 × 512 | High-density icon |
| `dark_icon.png` | 256 × 256 | Dark-theme icon |
| `dark_icon@2x.png` | 512 × 512 | High-density dark icon |
| `logo.png` | 960 × 240 | Light-theme horizontal logo |
| `logo@2x.png` | 1920 × 480 | High-density logo |
| `dark_logo.png` | 960 × 240 | Dark-theme horizontal logo |
| `dark_logo@2x.png` | 1920 × 480 | High-density dark logo |

See [Home Assistant brand guidelines](https://contributors.home-assistant.io/core/integrations/brands/). The `assets/stt-assistant-cover.png` is for README, posts, and GitHub social previews only; it is not part of the installed integration's `brand/` folder.

**Tiếng Việt:** Hình được tích hợp trong thư mục `brand/` theo quy chuẩn Home Assistant, không phải tải thêm từ website khác. Sau khi cập nhật logo, có thể cần tải lại trình duyệt hoặc khởi động lại Home Assistant để làm mới ảnh đang được cache.

**English:** The image assets are included locally and need no separate brand repository. Browser/Home Assistant caches can delay an icon update.
